## Codebase Patterns
- Rodar tudo da raiz. Checagem: `python3 -m compileall -q pipeline tests`; testes: `uv run --no-project --with pytest python -m pytest -q` (o Python local nao tem pytest).
- So stdlib + pytest (a correcao roda sem pandas e sem uv). Dinheiro sempre com decimal.Decimal; arredondar so na escrita com `.quantize(Decimal("0.01"))`.
- Caminhos vem de `pipeline/join.py`: `RAIZ = Path(__file__).resolve().parent.parent`; reutilize RAIZ/VENDAS/LOJAS em vez de usar o cwd.
- `pipeline.join.auditoria()` devolve (vendas, linhas_do_join, orfas, lojas_sem_venda) calculados dos CSVs de origem - use isso para citar orfas/loja 108 na pagina, sem digitar numeros a mao.
- `conftest.py` vazio na raiz poe o repo no sys.path: `from pipeline import x` funciona nos testes com `pytest` e `python -m pytest`.
- Padrao de teste: fixture `scope="module"` que roda o `main()` da etapa (regenera o entregavel na raiz, deterministico) e depois le o arquivo; stdout capturado com contextlib.redirect_stdout.
- Os CSVs de origem usam CRLF; csv.writer padrao tambem escreve CRLF, entao os entregaveis seguem o mesmo padrao. Abrir sempre com newline="" e encoding="utf-8".
- `ralph-run.log` (raiz) e o log do laco em andamento: nao commitar.
- Cada etapa expoe constantes `ENTRADA`/`SAIDA` (Path absoluto) e um `main()` que imprime linhas `[etapa] ...`. O fixture de teste de uma etapa roda os `main()` das etapas anteriores antes do seu, para nao depender da ordem dos testes nem de arquivo velho na raiz.
